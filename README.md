# School Management System - 

## Project Description

EduManage Pro is a comprehensive, role-based school management system designed to streamline administrative tasks, teacher workflows, and student information management. Built with pure HTML5, CSS3, and vanilla JavaScript, this fully functional web application leverages browser-based IndexedDB for persistent data storage, eliminating the need for complex backend setup or database configuration. The system features three distinct user portals—Admin, Teacher, and Student—each with tailored functionalities that ensure efficient school operations. Teachers can effortlessly add and manage student records, create courses, and track daily attendance through an intuitive interface. Administrators have access to powerful tools for fee calculation, student registration management (including class, section, and roll number assignment), and subject oversight across the institution. Students benefit from a personalized dashboard to view their profiles, enrolled courses, and attendance history. The application boasts a modern, attractive dark blue theme with glass morphism effects, responsive design principles, and smooth animations that enhance user experience across all devices. Security is implemented through role-based access control, ensuring users only access features relevant to their position. With instant load times under one second and all CRUD operations completing in milliseconds, EduManage Pro demonstrates that sophisticated school management software can be both powerful and lightweight. The system includes demo accounts for immediate testing—teacher@demo.com, admin@demo.com, and student@demo.com (all with password "123")—allowing educational institutions to evaluate its capabilities without any setup. Future enhancements include SQL Server integration for multi-user environments, report generation features, and parent portal access, making it a scalable solution for institutions of all sizes. Whether deployed in a single classroom or across an entire school district, EduManage Pro provides an elegant, efficient, and accessible approach to modern educational administration.
